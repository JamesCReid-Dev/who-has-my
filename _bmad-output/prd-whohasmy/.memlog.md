- (decision) Product: WhoHasMy - cross-platform lending tracker for inventory management
- (decision) Tech stack: Flutter (single codebase for Android, iOS, macOS, Chrome webapp)
- (decision) Single user per device, no accounts, local device storage only
- (decision) Statuses: available, loaned, in-maintenance; returns confirmed by owner only
- (decision) Contacts: address book import + manual entry; items: name, description, image, category, condition
- (decision) Notifications: both owner and borrower receive email/text alerts for approaching/overdue due dates
- (decision) Scale: max ~100 items per user; no privacy constraints; monetization TBD
